CRICKET UNIVERSE V3.0.1 — BUTTON / MODULE LOADER HOTFIX

Problem:
- The V3 app module failed before startup.
- GLTFLoader and SkeletonUtils internally import the bare module name "three".
- Without an import map, Chrome rejected the module graph.
- Because app.js never executed, all game buttons appeared unresponsive.

Fix:
- Added an import map resolving "three" to the exact Three.js 0.178 module.
- Cache-busted app.js so mobile Chrome fetches the corrected startup.

Install:
- Replace index.html on GitHub.
- app.js and styles.css are included for convenience but do not need replacing.
- No Supabase SQL is required.
