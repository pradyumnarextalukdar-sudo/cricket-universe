CRICKET UNIVERSE V1.3.4 — VISIBLE 3D ANIMATION FIX

Fixes:
- New server delivery events explicitly trigger the 3D delivery sequence.
- Fallback detects remote match-state progress if an event-feed update is missed.
- First ball of a new match can animate instead of being swallowed as a polling baseline.
- Bowler now has visible run-up, arm/leg movement and delivery action.
- Batter has backswing and follow-through.
- Fielders visibly run toward the ball.
- Keeper reacts on wickets.
- Ball trajectory is larger and more visible, with loft on sixes.
- Stumps added to make wicket animation readable.
- Animations are queued so two server deliveries cannot overlap visually.
- Cache-busting forces mobile Chrome to load the new animation code.
