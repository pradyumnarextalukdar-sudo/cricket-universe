10–11: Team-vs-team and pre-match presentation
12–14: Match / pitch / weather settings
15–16: Lineup comparison and player rating panel
17: Launch/continue presentation
18: Toss + pitch-condition overlay
19: Player/bowler intro stats lower-third
20: Live gameplay camera + bottom score HUD
21: Pause menu overlay
22: Tactics menu
23: Manage Bowlers table
24: Tactics / batting order entry point
25: Batting Order table

This project recreates the information architecture and sports-game interaction language
with original branding and original assets/code.
